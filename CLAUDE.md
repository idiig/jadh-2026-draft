# CLAUDE.md

## Communication

- Respond in Japanese for discussion, plans, and explanations
- Use English for code, comments, variable names, and technical terms
- Keep responses concise; avoid over-explanation

## Environment

- Use `direnv allow` to load the project environment
- Manage packages via `flake.nix` (Nix flake); do not install packages globally

## Writing

- Follow the `writing-clearly-and-concisely` skill: short sentences, active voice, no padding
- Review prose with the `sciwrite` skill before finalizing

## Conventions

- No over-engineering; do exactly what is asked
- No emoji unless explicitly requested
